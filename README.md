# قُرّة عيني 3.0 🌿

نسخة جديدة للقاء الوجاهي في إيطاليا وللعب عن بُعد بعد العودة لفرنسا. فيها 308 سؤالًا من النسخة السابقة + 156 موقفًا وسؤالًا جديدًا محدد الاختيارات = **464 سؤالًا وموقفًا**، وتحديات رسم وكسر خجل، وبوصلة توافق مستقلة من 20 سؤالًا.

## النشر على GitHub Pages
1. فكّي ضغط ZIP، وارفعي **كل الملفات السبعة** إلى جذر مستودع `qurrat-ayni` (ليس داخل مجلد فرعي): `index.html`, `style.css`, `app.js`, `questions-extra.js`, `v3-data.js`, `v3.js`, `README.md`.
2. من GitHub: `Add file → Upload files`، ثم `Commit changes`. إذا لم يسمح رفع ملفات بأسماء موجودة عبر الواجهة، عدّلي الملفات الموجودة باستبدال محتواها أو احذفي النسخ القديمة ثم ارفعي الجديدة.
3. انتظري اكتمال GitHub Actions / Pages، وافتحا الرابط في نافذة خاصة أو اعملا تحديثًا قويًا لإزالة الملفات المخزنة قديمًا.
4. اللعب عن بُعد: أحدكما ينشئ غرفة والآخر يدخل الرمز. انتظرا «متزامنين ♡». إذا بقيت المزامنة معلقة، أعيدا الاتصال. الاتصال يستخدم PeerJS / WebRTC وقد يتأثر بالشبكة.

## ما الجديد؟
- ثلاث قوائم مواقف جديدة: معًا بإيطاليا، بعد الرجعة لفرنسا، مواقف واقعية عن المصروف والحدود وغيرها.
- اختيارات محددة للمواقف بدل الاكتفاء بإجابات إنشائية؛ لا يوجد حكم آلي على الكرم أو التوافق.
- بوصلة توافق من 20 موقفًا: كل شخص يجيب على جهازه، وعند الضغط على «حفظ إجاباتي» في غرفة متزامنة تُرسل الاختيارات للطرف الآخر. **يجب على كل طرف اختيار «إجاباتي أنا»**؛ المقارنة تظهر بعد إرسال الطرفين. ويمكن استخدام نفس الجهاز عبر التبديل بين «إجاباتي أنا» و«إجابات الطرف الثاني».
- نجمة رمزية لكل اتفاق، وخصم نجمة لكل اختلاف، مع عرض التفاصيل وعدم اختزال التوافق في رقم.
- صندوق «سؤال بخاطري» مؤقت في الذاكرة، ولا يُرسل تلقائيًا.

## الخصوصية والحدود
- الإجابات والنتائج مؤقتة في ذاكرة التبويب؛ لا يوجد تسجيل دخول ولا حفظ دائم ولا حماية لحسابات. **إغلاق الصفحة يمسحها**.
- لا تستخدما الموقع لتبادل كلمات مرور أو بيانات حساسة. اتصال WebRTC يُنشأ بمساعدة خدمة إشارة عامة، ورمز الغرفة ليس حماية قوية ضد المتطفلين.
- البوصلة تعتمد على **تطابق الاختيارات حرفيًا**، ولا تقيس صلاحية الزواج. الاختلاف حول حدود شخصية أو حق أساسي يحتاج نقاشًا منفصلًا، حتى لو كانت النجوم كثيرة.
- عند اختيار الإجابة على المواقف الجديدة في القسم المنفصل، لا تنتقل الاختيارات تلقائيًا للطرف الآخر؛ ناقشاها شفهيًا أو استخدما استبيان التوافق المتزامن.
- إذا كان اللعب عن بُعد يتعطل كثيرًا، فالحل الأقوى مستقبلًا هو قاعدة بيانات فورية بحسابات وصلاحيات، مثل Supabase أو Firebase.


## تحديث 3.1
- العنوان: «من فرنسا لإيطاليا… خطوة بخطوة» من غير «بين قلبين».
- اختيار موضوع فرعي واضح: أسئلة اللقاء منفصلة عن تحديات اللقاء، وأقسام المسافة والمواقف منفصلة.
- قسم مستقل «رفاهيات ولا أساسيات».
- في البطاقات: الجواب الحر أولًا، والخيارات لا تظهر إلا عند طلبها، وتشمل مواقف غير مثالية.
- أسئلة عن الوفرة والكرم، السكوتر والبسكليت والتزلج، البرمجة والرسم، المخاوف، ودور المرأة والمسؤوليات.
- حذف الإشارة للأغاني من التحديات.
- وضع الأسئلة المالية في نهاية استبيان التوافق.
- الأسئلة الحرة في بطاقات V3.1 غير مشتركة تلقائيًا بين الأجهزة؛ يمكن مناقشتها صوتيًا. استبيان التوافق هو الذي يرسل الاختيارات عند الحفظ.
- للتحديث على GitHub: ارفعي كل الملفات السبعة إلى مستودع qurrat-ayni-hikayatuna فقط.
